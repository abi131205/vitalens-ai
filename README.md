# VitaLens AI 🧠

VitaLens AI is an AI-powered health assistant that predicts potential health risks based on user inputs such as symptoms, sleep patterns, physical activity, and stress levels.

## 🚀 Features

* Smart health risk prediction
* Multilingual symptom support (Google Translation)
* Preventive health suggestions
* Clean and user-friendly interface

## 🛠 Tech Stack

* Python
* Flask
* HTML/CSS
* Google Translation API

## ⚙️ How It Works

The system takes user inputs and analyzes them using rule-based logic:

* Identifies potential health risks
* Provides explanations
* Suggests preventive actions

## 📌 Assumptions

* User inputs are basic indicators of health
* This tool is not a replacement for medical diagnosis

## ⚠️ Disclaimer

This application provides AI-based predictions and should not be considered medical advice.
